## 核心结果

| 实验 | 结果 |
|------|------|
| **clean 训练**（5 seeds）| best_SR 53.2% |
| **curriculum v1 → v2** | 40.4% → 48.0%（正常性能降 ≤5pp 达标）|
| **深度必要性** | 纯避障 baseline 34.4% → const_depth 6.0%（−28.4pp，配对 4/5 显著）|
| **输入依赖** | 速度/目标方向 5/5 显著；深度 4/5 |
| **结构消融** | RGB/浅CNN 各 −5.2pp；无特权 Critic −12.9pp |
| **BC 基线** | BC 32.0% < RL 53.2%（−21.2pp）|
| **跨场景泛化** | 单场景 0% → 3 场景联合 27-37%（弱，未达 40-50%）|
| **PX4 注册** | 悬停回放中央深度 0.97m ≈ 高度 0.95m（一致）|

## 结论

1. **深度对避障必要**（纯避障强成立）
2. **深度 > RGB**，特权 Critic 必要
3. **RL > BC**
4. **curriculum v2** 正常性能达标 + 保留尺度鲁棒性
5. **跨场景泛化弱** → 诚实收缩为方法边界（需 domain randomization）
6. **PX4** 相机一致化 + 悬停回放验证（非全飞行闭环）

## 关键边界

- 跨场景泛化失败（27-37%）
- PX4 仅悬停回放
- 4 场景训练 checkpoint 可复现性缺陷（未采用）
