# PX4 定点悬停观测测试

日期：2026-08-02。验证只读观测桥在真实 PX4 SIH 悬停位姿下的端到端渲染。

## 方法

1. 启动 PX4 SIH（`sihsim_quadx`），`MavlinkOffboardClient` 执行 Offboard 起飞至 1 m、悬停 10 s，录播 `LOCAL_POSITION_NED` + `ATTITUDE`（20 Hz，200 样本）。
2. 裁掉前 40 个起飞瞬态样本，保留 160 个稳定悬停样本（高度 0.886–1.085 m，均值 0.945 m）。
3. 只读观测桥回放：位姿经 `Px4SceneAlignment` 映射 → gsplat 渲染 64×64 深度 → 构造 `{depth, vec}`，全程不发送控制。
4. 录播后 PX4 已停止，无残留进程。

## 结果（160 样本）

| 指标 | 值 |
|------|-----|
| 有效深度比例 | 1.000（invalid_ratio 全为 0） |
| 深度均值 | 4.054 ± 0.151 m（3.856–4.444） |
| 深度最小值 | 1.837 ± 0.206 m |
| 速度 | 均值 0.159 m/s、最大 0.307 m/s |
| 场景位置漂移 | 最大 0.247 m |
| vec 语义 | 近零速度 + 锚点目标方向，与 `visual_drone_env._get_observation` 一致 |

## 结论

真实 PX4 悬停位姿映射后渲染**稳定且全部有效**：定点悬停下深度统计低方差，说明坐标映射、相机姿态与渲染链路在悬停点一致。只读观测桥端到端可用。

遥测证据见 `hover_telemetry.json`。仍缺：在线（飞行中）观测桥闭环、以及重训 V3 前训练侧渲染内参与桥上内参（fx≈97.14）对齐。
