# 视觉必要性验证（深度是否必要）

日期：2026-08-03。环境：对齐窄视场相机（fx≈97.14）+ 0.5m 碰撞半径 + 真实场景碰撞几何。模型：curriculum robust-best seed1/2。评估：50 episodes（seed 20260803），对比 `baseline`（有深度）vs `const_depth`（深度替换为固定 5m）。

## 结果（SR %）

| 场景 | 模型 | baseline | const_depth | 深度贡献 |
|------|------|:---:|:---:|:---:|
| 纯空旷 (avoid=0.0) | seed1 | 76.0 | 74.0 | -2pp |
| 纯空旷 | seed2 | 68.0 | 62.0 | -6pp |
| 纯避障 (avoid=1.0) | seed1 | 24.0 | 16.0 | -8pp |
| 纯避障 | seed2 | 22.0 | 16.0 | -6pp |

## 结论：视觉必要性未建立

1. **纯空旷**：深度几乎无贡献（-2~6pp）——直飞可达，不需要深度。
2. **纯避障**（直线被障碍挡住）：去掉深度仍只掉 **6-8pp**，const_depth 仍有 16% 成功率——**深度连避障都不必要**。
3. 场景障碍太稀疏/边缘，策略靠速度+目标方向向量即可部分绕过障碍。

## 论文含义

- 当前任务撑不起强「视觉导航」主张。深度视觉是弱-中等贡献，非主驱动。
- 要建立视觉必要性需**重新设计任务**，使障碍/目标**仅深度可见**且无法盲飞绕过：
  - 更密/真正阻挡的障碍（直线必撞，绕过必须提前看见）；
  - 目标被遮挡（必须读深度找目标/绕行）；
  - 或去掉部分向量信息（如目标方向受扰）。
- 否则论文只能如实报告「深度是中等增强」，视觉主张需弱化。
