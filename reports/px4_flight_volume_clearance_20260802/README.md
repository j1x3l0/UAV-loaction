# PX4 飞行体积碰撞净空门禁

日期：2026-08-02。输入：`gate_mid_new.ply`（265,329 点，scene 范围 x∈[-8,8]、y∈[-4,4]、z∈[-0.1,3.5]）+ `px4_gate_mid_alignment.json` 坐标映射。

## 方法

- 飞行体积定义为映射后的场景飞行带：scene 云范围在无人机高度带（z∈[0.5,3.5]）映射到 PX4 NED 得到的盒。
- 在 NED 盒内以 0.5 m 网格采样，经 `Px4SceneAlignment` 映射到 scene，查询到碰撞点云最近距离。
- 判据：飞行体积**裸盒的 min 净空不适用**（盒包含门体结构本身，min≈0 是预期）。正式判据是「操作净空下场景连通自由空间是否足够大」，复用 `ScenePointCloudGeometry.build_navigation_grid`。

## 结果

| 指标 | 值 |
|------|-----|
| 飞行带盒净空分布 | min 0.006 m、p5 0.12 m、中位 1.73 m、max 7.96 m |
| 盒内距障碍 <0.45 m 采样占比 | 17.6%（含门体内部，预期） |
| **连通自由空间 @0.45 m 净空** | **5677 节点 = 153.3 m³** |
| 判据（最小可接受自由体积） | 10.0 m³ |
| **门禁结论** | ✅ PASS |

补充：净空≥0.25/0.45/0.75/1.00/1.50 m 时连通自由空间分别为 221/153/75/30/0.1 m³。1.5 m 近乎为零符合任务设计——场景是窄走廊（16×8×3.6 m），无人机需贴近门体飞行。

## 结论

映射后的 PX4 飞行区域在操作净空（0.45 m）下有充足连通自由空间，无人机有地方安全飞行。飞行体积净空门禁通过。`formal_v3_ready` 仍为 false，剩余门禁：只读观测桥、遥测回放与定点悬停渲染。
