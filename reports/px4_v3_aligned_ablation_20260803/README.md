# 对齐 V3 输入依赖性消融

日期：2026-08-03。环境：对齐窄视场相机（fx≈97.14，36° FOV）+ 0.5m 碰撞半径 + 真实场景碰撞几何。评估：50 episodes/消融（seed 20260803）。

## 结果（SR %）

| 模型 | baseline | const_depth | no_velocity | no_target_dir |
|------|:---:|:---:|:---:|:---:|
| clean_baseline（1500ep） | 50.0 | 28.0 | 2.0 | 0.0 |
| cur_robust_seed1 | 52.0 | 40.0 | 4.0 | 0.0 |
| cur_robust_seed2 | 36.0 | 34.0 | 4.0 | 2.0 |

## 结论（视觉必要性门控）

1. **策略严重依赖向量输入**：去掉速度 → SR 2-4%；去掉目标方向 → SR 0-2%。两者任一缺失即几乎无法导航。
2. **深度视觉是中等贡献**：`const_depth`（深度替换为固定 5m）只导致 -2~22pp 下降（seed2 仅 -2pp），远小于向量缺失的影响。
3. **当前对齐任务下视觉必要性存疑**：策略主要靠 14D 向量（速度+目标方向）导航，深度图非主驱动。

## 论文含义

- 若 V3 主张「视觉导航」，需在任务层面让深度成为必要输入（如目标被遮挡、障碍仅深度可见、更复杂场景），否则视觉贡献不显著。
- 如实报告方向：本任务中深度是中等贡献者——这本身是对「3DGS 视觉导航」的诚实限定，可与 GRaD-Nav 对比（其用 RGB + 特权向量，同样存在输入依赖问题）。
