# Phase V2 gate_mid 真实 3DGS 衰减评估

## 实验设计

- 模型：V1-Baseline-S1 最佳检查点
- 渲染器：真实 gsplat，gate_mid，64×64 depth
- 退化轴：Gaussian 数量、分辨率、深度噪声、光照、视角覆盖
- 每轴 5 档，每档 50 episodes，共 1250 episodes
- 所有档位共享相同的 50 个 episode seeds（20260726–20260775）

## 基线复核

独立 200-episode clean 评估：

- 成功率：75.5%
- 95% Wilson CI：69.1%–80.9%
- 碰撞率：24.5%
- 超时率：0%

正式 Phase V2 的共享 50-seed clean 对照成功率为 68%。因此训练期间基于
20 episodes 得到的 90% 不能视为稳定总体性能，Gate G3 尚未稳健通过。

## 主要结果

| 退化轴 | clean/最高质量 SR | 最严重档 SR | 主要现象 |
|---|---:|---:|---|
| Gaussian | 68%（100%） | 68%（5%） | 5% 时平均奖励小幅下降，SR 未单调衰减 |
| 分辨率 | 66%（64px） | 56%（4px） | 最明显 SR 下降；8px 最低为 52% |
| 深度噪声 | 68%（σ=0） | 68%（σ=0.2） | 当前噪声范围内基本不敏感 |
| 光照 | 68%（0EV） | 68%（4EV） | 五档完全一致，验证 depth-only 负对照 |
| 视角覆盖 | 68%（360°） | 68%（45°） | SR 未降，但平均奖励 369.7→124.9，超时率升至16% |

## 临界点与排序

- 所有轴均未出现 SR < 50%，因此 50% 临界点不存在。
- 所有轴均未出现 SR < 20%，因此 20% 临界点不存在。
- Gate G4（至少一轴从 >80% 跌到 <20%）未通过。
- 按成功率下降排序：分辨率最致命。
- 按平均奖励和超时恶化排序：视角覆盖最致命。
- Gaussian 稀疏和当前深度噪声范围未形成清晰单调退化。

## V3 决策

暂不直接进入 V3 鲁棒训练。应先：

1. 提升或重训 clean baseline，使 200-episode SR 稳定超过 80%。
2. 将分辨率最低档扩大到更有物理意义的退化方式，避免 8px 与 4px 插值趋同。
3. 扩大深度噪声范围，并增加结构性空洞、偏置和深度失真。
4. 重新审查 Gaussian importance 定义及场景/碰撞几何是否一致。
5. 将视角轴的核心指标改为 SR、超时率和平均奖励联合判定。
