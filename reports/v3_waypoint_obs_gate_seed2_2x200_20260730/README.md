# V3 路径点观测诊断门控

日期：2026-07-30

## 目的

诊断上一轮 hybrid-geodesic 策略在避障任务上失败，是否主要来自观测只包含
最终目标方向，而训练奖励要求策略沿不可见的局部安全路径转弯。

本实验用规划器提供的局部路径点方向替代最终目标方向。该输入依赖完整场景
几何，因此属于**分层规划/特权路径点诊断**，不能表述为端到端视觉导航。

## 协议

- seed：2；
- 训练：100 updates，8 environments，204,800 steps；
- 渲染器：真实 gsplat；
- 视觉与碰撞：同一 `gate_mid_new_gs.ply`；
- 训练课程：避障任务比例 10% -> 30% -> 50%；
- 独立评估：base seed `20260728`；
- baseline、const-depth各200 episodes；
- clear与avoidance分层统计。

## 结果

| 配置 | 总SR | Wilson 95% CI | Clear SR | Avoidance SR | Collision | Timeout |
|------|-----:|--------------:|---------:|-------------:|----------:|--------:|
| baseline | 92.5% | 88.0–95.4% | 96.9% | 88.3% | 7.5% | 0.0% |
| const-depth | 84.0% | 78.3–88.4% | 96.9% | 71.8% | 16.0% | 0.0% |

baseline相对const-depth提高8.5个百分点。avoidance分层提高16.5个百分点。

## 门控判定

预设标准：

- clear >= 80%：通过；
- avoidance >= 60%：通过；
- 总体 >= 70%：通过；
- timeout <= 10%：通过；
- baseline相对const-depth至少提高20个百分点：**未通过**。

总体门控判定为失败，不扩展多种子训练。

## 解释

局部路径点方向把上一轮avoidance SR从11.7%提高到88.3%，证明：

1. 场景、采样、质点动力学和PPO容量足以执行可行路径；
2. 原端到端任务的主要瓶颈是最终目标观测无法表达需要绕行的局部子目标；
3. 分层规划器 + 局部控制器是一条可行路线。

但是const-depth仍达到84.0%，说明特权路径点已经携带大部分避障信息，视觉深度
并非主要决策来源。因此本结果只能作为层次化规划上界和问题诊断，不能支持
“3DGS视觉策略学会自主避障”的主张。

## 决策

- 停止路径点观测多种子扩展；
- 不继续调节测地奖励；
- 保留该实验作为规划器上界；
- 下一步转入PX4 + Gazebo接口验证准备；
- 后续若恢复端到端路线，应优先研究时序观测、局部地图或显式视觉规划，而不是
  继续增加训练episodes。
