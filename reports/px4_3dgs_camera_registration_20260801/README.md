# PX4–3DGS 相机注册初检

- 输入：`gate_mid_new_gs.ply`、训练位姿0/77/154/231/308及对应原图。
- 方法：同时使用 CPU Gaussian-center 投影与 gsplat GPU 完整渲染，对比 Nerfstudio OpenGL 位姿转 OpenCV 光学轴和未转换候选。
- GPU完整竖屏缩放结果：正确转换覆盖率1.000、RGB MAE 0.1618、亮度相关0.2266；错误候选分别为0.9233、0.1945、-0.1425。
- GPU策略64×64中心裁剪结果：正确转换覆盖率1.000、RGB MAE 0.1869、亮度相关0.0306；错误候选分别为0.9154、0.2016、-0.1700。
- 判定：轴约定和策略相机内参初步通过；正确转换在几何结构和指标上均优于错误候选，但绝对亮度相关仍低，不能作为照片级渲染质量结论。
- 性能：首次 CUDA 初始化完成后，265,631 Gaussian 的64×64渲染约1.8 ms；先前60秒等待是初始化/会话轮询误判，不是持续 rasterization 故障。

CPU原始指标见 `result.json`；GPU结果见 `result_gpu.json` 和 `result_gpu_policy64.json`，拼图文件使用对应的 `montage_*.png`。正式 V3 仍须通过30位姿统计、飞行体积净空和在线观测桥门禁。
