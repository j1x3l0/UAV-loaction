# 对齐 V3 退化轴补齐（5 轴）

日期：2026-08-03。在**对齐环境**（fx≈97.14 窄视场相机 + 0.5m 净空 + 真实场景碰撞）重做 V2 的 5 轴退化评估。模型：clean 基线（1500ep）+ curriculum robust-best seed1。评估：5 轴 × 5 档 × 50ep。

## 结果（SR %）

| 轴 | clean 基线 | curriculum seed1 |
|----|:---:|:---:|
| Gaussian 稀疏化（100%→2%）| 50→34 | 52→32 |
| 分辨率（64→2px）| 50→40 | 52→50 |
| 深度噪声（0→1σ）| 50→48 | 52→52 |
| 光照（EV0→4）| 50（不变）| 52（不变）|
| **视角不确定（360°→45°）** | **50→18** | **52→54** |

## 结论

1. **视角不确定性是对齐窄视场的重要退化轴**：clean 基线在 45° 视角下掉到 **18%**（窄视场 + 受限视角组合最致命）。
2. **curriculum 鲁棒训练显著改善视角鲁棒性**：seed1 在 45° 下**不掉**（54%），对比 clean 的 18%。
3. **分辨率**：curriculum 更鲁棒（50% vs clean 40% @2px）。
4. **光照**：深度-only 策略天然不变（负对照确认）。
5. **稀疏化/噪声**：两者中度鲁棒，curriculum 略优。

## 意义

- 补齐了 V2 的对齐版退化曲线（原 V2 是 legacy-unaligned）。
- 深度尺度（最致命轴）已在 V3 对照中覆盖（0.25x 4/5 seed 显著）。
- **新发现**：对齐窄视场下，视角不确定性成为与深度尺度并列的重要脆弱轴，且 curriculum 对此轴改善最大——论文新增一个可报告的鲁棒性发现。
