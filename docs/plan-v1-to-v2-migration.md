# 研究计划迁移记录：v1 (向量RL) → v2 (3DGS视觉RL)

> 记录时间：2026-07-21
> 触发原因：子课题A前3周任务在3天内完成，速度远超预期。重新评估后在原计划基础上
> 升级技术路线——从纯向量状态扩展到基于3D Gaussian Splatting的视觉输入。

---

## 一、核心变化

| 维度 | v1 (原计划) | v2 (新计划) |
|------|-----------|-----------|
| **观测空间** | 14D完美向量（位置、速度、目标方向、障碍物信息） | 64×64深度图 + 速度(3D) + 目标方向(3D) |
| **网络架构** | MLP 128×2 (5万参数) | CNN 3层 + 共享MLP (~200万参数) |
| **训练场景** | 3个硬编码障碍物球，20×20×10m | 5个手机拍摄真实场景，3DGS重建 |
| **核心科学问题** | 向量噪声是否存在相变？ | 3DGS渲染质量下降→策略行为是否存在相变？ |
| **退化方式** | 各维度独立高斯噪声 | 5轴结构化退化（GS数量、分辨率、视角、光照、深度噪声） |
| **对比baseline** | SAC环境策略 (Wang et al. ICRA 2025) | 可微分RL (GRaD-Nav IROS 2025) + BC (SOUS VIDE RA-L 2025) |
| **差异化定位** | RL策略的噪声鲁棒性 | **3DGS重建质量→策略安全边界（Stanford证明能飞，我们回答不能飞的条件）** |
| **目标会议** | 未明确 | ICRA 2027 (~2026年9月截止) |
| **时长** | 8周 | 3周 |
| **算力** | ¥800-1,200 (本地CPU为主) | ¥218-400 (云GPU, RTX 3080/4090) |

## 二、实验设计变化

### 2.1 保留的实验（从v1迁移）

| v1实验 | v2对应 | 变化 |
|--------|--------|------|
| A1噪声类型分解 (6组×5σ) | V2渲染质量衰减 (5轴×5水平) | 退化轴从独立高斯噪声→结构化视觉退化 |
| A2噪声感知训练 (4组) | V3鲁棒训练 (4组) | Clean/Fixed/Rand/Curric 框架不变，退化方式变 |
| A2消融实验 | V3消融 (4组) | 从维度消融→网络组件消融 |
| 跨噪声水平泛化 | V3跨场景泛化 | 从σ泛化→场景泛化 |

### 2.2 新增的实验（v1没有）

| 实验 | 为什么新增 |
|------|-----------|
| 3DGS场景重建 (5场景) | 路径4的基础设施 |
| 组合退化测试 (V2.6) | 3DGS退化有空间结构，轴间交互不可忽略 |
| 视觉PPO vs 可微分RL (V3.2) | 与Stanford方法直接对比，增强论文说服力 |
| BC baseline (V3.2) | SOUS VIDE式行为克隆，对比RL和非RL方法 |
| 定性可视化 (轨迹图、渲染对比) | 视觉域的优势——退化效果可以直接看到 |

### 2.3 放弃的实验（暂不迁移）

| v1实验 | 放弃原因 | 后续计划 |
|--------|---------|---------|
| **子课题B全部** (环境策略SAC联合训练) | 视觉RL本身创新点已够，加SAC分散焦点 | 作为后续工作（future work） |
| A* / RRT baseline对比 | 3DGS环境中路径规划不是重点，鲁棒性是重点 | 如有余力可在Discussion中引用对比 |
| PID Lagrangian / CPO | 安全RL理论在视觉退化场景中需要重新形式化，工作量太大 | 作为后续工作 |

## 三、竞争格局变化

### v1的定位（向量RL社区内）

```
向量RL噪声鲁棒性: 文献中没有系统性的衰减曲线测量
→ 贡献：基准性工作
→ 风险：创新度中等，纯向量状态在真机上不现实
```

### v2的定位（3DGS+RL社区内）

```
谁做了:        做了什么:            没做什么:
GRaD-Nav       3DGS+可微分RL能飞    退化下的鲁棒性
SOUS VIDE      3DGS+BC能飞105次    重建质量要求
GRaD-Nav++     加语言指令           鲁棒性分析
GaussFly       对比学习+RL          退化分析
EmbodiedSplat  地面导航+iPhone      无人机+退化
─────────────────────────────────────────────────
我们:           3DGS重建质量↓→      策略安全边界
                衰减曲线+临界点     (全部空白)
```

**关键变化**：从"在一个小圈子里做第一个"变成"在一个热圈子里做唯一一个问反面问题的人"。

## 四、风险变化

| 风险 | v1 | v2 | 变化原因 |
|------|-----|-----|---------|
| 方法不收敛 | 低（MLP已验证收敛） | **中**（视觉RL样本效率更低） | 应对：D1做100ep微型测试，不收敛立即BC预热 |
| 被抢先 | 低（向量RL噪声方向冷门） | **中**（3DGS+RL非常热） | 应对：3周快出，差异化定位"反面问题" |
| 实验结果不显著 | 低（向量噪声大概率有相变） | 中（视觉退化可能没有突变） | 应对：渐进衰减也是有用发现 |
| 算力不够 | 低（本地CPU） | **中**（依赖云GPU） | 应对：充¥400，远超估算需求 |
| 开源代码跑不通 | N/A | **高**（GRaD-Nav依赖复杂） | 应对：降级为PPO vs BC对比，不强制DDRL |

## 五、论文叙事变化

### v1 一句话
> "RL策略对状态估计噪声存在相变现象——存在一个临界噪声水平，超过后策略突然崩溃。"

### v2 一句话
> "用手机拍视频重建的3DGS环境可以训练出能飞的策略——但重建质量差到什么程度它就不能飞了？我们给出第一个系统性答案。"

| 章节 | v1 | v2 |
|------|-----|-----|
| Introduction | 噪声+RL鲁棒性的空白 | **3DGS+RL的部署安全空白** |
| Related Work | 域随机化、安全RL | **+3DGS仿真、视觉RL导航** |
| Method | 噪声注入框架 | **3DGS渲染管线 + 5退化轴定义** |
| Experiments | 衰减曲线+鲁棒训练对比 | **同框架，但退化源从数学噪声→物理渲染退化** |
| Discussion | 安全RL启示 | **+3DGS重建的实用指导 + sim-to-real启示** |

## 七、决策记录

### 为什么现在切换？

1. **速度验证**：3天完成原定3周任务 → 应该做更ambitious的事
2. **竞争窗口**：Stanford 2025年发了3DGS+无人机，但鲁棒性完全空白 → 窗口正在关闭
3. **差异化最大化**：与其在向量RL社区做增量改进，不如在3DGS+RL社区做唯一问反面问题的人
4. **论文叙事更强**："手机拍视频→训练→部署，但什么时候会失败？"比"加高斯噪声测衰减"更有传播力

### 为什么保留v1文件？

- v1的子课题A数据作为v2论文中的"preliminary study in simplified vector setting"
- 子课题B（环境策略）是有效的后续方向，可以写在Discussion中
- 两版对照可以作为论文的supplementary material
