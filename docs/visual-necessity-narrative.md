# 视觉必要性叙事定稿（2026-08-07）

整合 D3-lite、sv_1007 输入消融、纯避障消融与旧 D1 的证据，形成论文自洽的
"视觉（深度）必要性"叙事。

## 核心主张

> **深度图对 3D 视觉导航的障碍规避是必要的，且必要性强度随障碍密度/场景复杂度
> 单调增强。** 在稠密/复杂场景中深度是唯一可靠的避障信号；在极简场景中深度可被
> 其他线索（速度、目标方向）替代，必要性随之减弱。

## 证据链

### 1. 稠密合成走廊（D3-lite）——深度严格必要 ✅

`reports/px4_d3lite_visual_necessity_20260803/`

| 条件 | SR | 结论 |
|------|:---:|------|
| baseline（有深度）| **54%** | 可学 |
| const_depth（去深度）| **0%** | 崩塌 |
| 5-seed 配对 | 4/5 显著 (p<0.001) | 深度严格必要 |

**意义**：障碍密度最高的任务，深度必要性最强（54→0pp）。

### 2. sv_1007 纯避障——深度强必要 ✅

`reports/px4_sv1007_avoid_ablation_20260806/`

| 条件 | SR | 结论 |
|------|:---:|------|
| baseline | **34.4%** | 可学 |
| const_depth | **6.0%** | 崩塌（−28.4pp）|
| no_velocity | 6.4% | 同样关键 |

**意义**：真实大场景（完整 gate，22×25×9m）纯避障下，深度是必要信号（5 seeds 一致）。

### 3. sv_1007 混合任务——深度中等必要 ✅

`reports/px4_sv1007_ablation_20260806/`

| 消融 | SR | vs baseline |
|------|:---:|:---:|
| baseline | 54.0% | — |
| const_depth | 37.2% | **−16.8pp** |
| no_velocity | 7.2% | −46.8pp |
| no_target_dir | 0.8% | −53.2pp |

**意义**：混合任务下目标方向/速度是决定性输入（去后崩塌到 <8%），深度提供中等但实质
的 16.8pp 增益。

### 4. 旧 D1（gate_mid_new 纯避障）——诱导失败 ❌

`docs/visual-necessity-redesign.md`：纯避障 radius 扫描未能诱导深度必要性（baseline
与 const_depth 一起崩塌）。**场景太小/太简，深度可被其他线索替代。**

### 5. V3c 跨场景——场景特定，不泛化 ⚠️

`reports/px4_v3c_cross_scene_20260807/`：sv_1007 ↔ left/right zero-shot 泛化 0%。

**意义**：CNN 编码器场景特定——这是深度必要性的**边界**（必要性在训练场景内成立，
不跨场景泛化），也解释为何需 domain randomization。

## 叙事主线（论文可写）

```
深度必要性 ∝ 障碍密度 × 场景复杂度

D3-lite（合成稠密）: 深度必要 54→0  (最强制)
sv_1007 纯避障       : 深度必要 34→6  (−28.4pp)
sv_1007 混合任务     : 深度中等 54→37 (−16.8pp)
gate_mid_new 纯避障  : 深度不必要（场景过简，D1 失败）

→ 单调关系：任务越需要精细避障，深度越不可替代。
→ 边界：模型场景特定（V3c 泛化失败），跨场景需 domain randomization。
```

## 结论与建议

- **视觉必要性叙事成立**：深度在避障中必要，强度随复杂度增强。D1 的"失败"不是矛盾，
  而是叙事的下界（极简场景深度非必要）。
- **论文写法**：以"深度必要性随障碍密度增强"为统一主张，D1 作为下界对照，D3-lite +
  sv_1007 作为上界/中界证据。
- **剩余风险**：V3c 泛化失败是方法边界，需在论文 limitations 如实报告（或用
  domain randomization 部分缓解）。
