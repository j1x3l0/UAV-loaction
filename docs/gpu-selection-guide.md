# 矩池云 GPU 选卡指南

> 适用于 UAV Visual RL 项目 (v2 3DGS + PPO)
> 2026-07-22

## 推荐配置

| GPU | 显存 | 建议 | 原因 |
|-----|------|------|------|
| **A4000** | 16GB | ⭐⭐⭐ 首选 | 跑满默认配置，余量充足，性价比高 |
| **3080 Ti** | 12GB | ⭐⭐ 推荐 | 比 3080 多 2GB，基本不用降级 |
| **3080** | 10GB | ⭐ 可用 | 卡在边界线，必须降级参数 |
| **3090** | 24GB | ⭐⭐⭐ 奢侈 | 可同时跑训练+评估，但贵 |
| 3080 共享 | ~8-9GB | ❌ 不推荐 | 共享显存更不可控 |

## 3080 (10GB) 降级方案

默认配置需要 6-8GB 峰值显存，10GB 刚好卡线。出现 OOM 时按顺序调整：

| 参数 | 默认 | 降级值 | 省显存 |
|------|------|--------|--------|
| `num_envs` | 8 | 4 | ~40% |
| `rollout_steps` | 2048 | 1024 | ~30% |
| `minibatch_size` | 64 | 32 | ~15% |
| CNN 通道 | [32,64,64] | [16,32,32] | ~30% |

## 镜像选择

```
PyTorch 2.1.2 + CUDA 12.1 + Python 3.10
```

**不要追新**：PT 2.4 / CUDA 12.4 的额外 VRAM 开销在 10GB 卡上是浪费。CUDA ≥12.0 是 gsplat 的硬要求。

## 启动后验证

```bash
python -c "
import torch
mem = torch.cuda.get_device_properties(0).total_mem / 1e9
print(f'可用显存: {mem:.1f} GB')
print('建议配置:', '默认' if mem >= 12 else '降级')
"
```
