============================================================
一、Ferede et al. (2025) — One Net to Rule Them All
   ICRA 2025, TU Delft Micro Air Vehicle Lab
   arXiv: 2504.21586
============================================================

[核心贡献]
第一个跨平台通用无人机竞速神经网络控制器。单个网络同时控制
3 英寸和 5 英寸两台物理差异巨大的竞速无人机，无需重训练。

[实验设计 — 4 个域随机化水平]

  水平      含义                              Sim-to-Real   速度    鲁棒性
  ────────  ────────────────────────────────  ────────────  ──────  ──────
  0%        仅用标称参数训练                  失败           —       —
  10%       参数在标称值 +/-10% 内随机         成功           最快    最低
  20%       参数在标称值 +/-20% 内随机         成功           中等    中等
  30%       参数在标称值 +/-30% 内随机         成功           最慢    最高

[被随机化的物理参数]

  质量 (m)                 — 直接影响惯性
  惯性矩阵 (I)              — 三轴转动惯量
  电机常数 (KP, KR, KA, KG) — 推力/扭矩系数
  电机转速限制               — 3寸: 305-4888 rad/s, 5寸: 238-3296 rad/s
  电机时间常数 (tau)         — U(0.01, 0.1) 秒
  气动阻力系数 (KRD)         — U(2, 8)
  推力/扭矩系数 (k)          — V(0.1, 0.3) 和 V(10, 30)

["%"的精确含义]

百分比 = 以标称值为中心，向两侧扩展的范围比例。

  标称质量 m0 = 0.5 kg
  10%: m ~ U(0.45, 0.55)   = U(m0*0.9, m0*1.1)
  20%: m ~ U(0.40, 0.60)   = U(m0*0.8, m0*1.2)
  30%: m ~ U(0.35, 0.65)   = U(m0*0.7, m0*1.3)

[为什么这样设计 — 4 个关键原因]

  1. 0% 作为对照: 证明不随机化一定失败。策略会过拟合到模拟器
     的数值误差，完美模拟器不存在。
  2. 递增设计: 10/20/30 形成梯度，可直接测量"鲁棒性-速度"
     的 trade-off 曲线。
  3. 上界 30%: 超过 30% 后性能下降太严重（无人机无法稳定飞行），
     不需要更高。
  4. 物理意义: 百分比直接对应真实无人机制造公差的范围
     （同型号无人机质量差异通常在 +/-5-15%）。

[对你的 A2 实验的启发]

  你的 A1 用的是绝对 sigma 水平 [0.1, 0.5, 1.0, 2.0, 5.0]。
  Ferede 用的是相对百分比 [0%, 10%, 20%, 30%]。
  两种方法论互补：
    A1/a 绝对水平: 测量"噪声多大时系统崩溃"
    Ferede 相对水平: 测量"相对不确定性下如何 trade-off"

二、Peng et al. (2018) — Dynamics Randomization
   ICRA 2018, UC Berkeley / OpenAI
   DOI: 10.1109/ICRA.2018.8460528
============================================================

[核心贡献]
在仿真中训练的机械臂推物块策略，零样本迁移到真实机器人。
用 PPO + LSTM，通过在仿真中随机化动力学参数，迫使策略学习
适应性行为而不是利用特定模拟器的特性。

[实验设置]
  任务: 7-DOF Fetch 机械臂推物块到随机目标位置
  状态空间: 52 维 (关节位置/速度 + 夹爪位置 + 物块位姿/速度)
  动作空间: 7 维 (相对关节角偏移)
  算法: PPO + LSTM (循环策略网络, 用于隐式系统辨识)

[原则 1: 每 Episode 固定，Episode 间随机]

  Episode 1: m=0.8kg, damping=3.2, friction=1.1  <- 全程不变
  Episode 2: m=1.3kg, damping=5.1, friction=0.7  <- 全程不变
  Episode 3: m=0.6kg, damping=4.0, friction=1.5  <- 全程不变

  为什么: 如果每个 timestep 都随机化，策略学到的是"忽略所有
  动力学参数"，而不是"从状态历史中推断参数"。固定一个 episode
  迫使策略学习隐式系统辨识（通过观察状态转移推断当前动力学）。

  这也是为什么 Peng 用 LSTM — 循环网络可以在隐状态中记住
  过去的状态转移，从而"推断"当前环境的动力学参数。

  注: 你的策略是 MLP (无记忆) vs Peng 用 LSTM。这是你们
  方法论的差异点——无记忆策略无法做隐式系统辨识，但训练更简单。

[原则 2: 范围要覆盖真实世界，不需要精确匹配]

  随机化参数及其范围:
  ┌──────────────────────┬──────────────────────────┐
  │ 参数                  │ 范围（均匀分布）           │
  ├──────────────────────┼──────────────────────────┤
  │ 各连杆质量            │ U(0.5*, 1.5*)            │
  │ 关节阻尼              │ U(0.5*, 1.5*)            │
  │ 物块质量              │ U(0.25*, 4.0*)  ← 故意更宽│
  │ 物块摩擦系数           │ U(0.5*, 2.0*)            │
  │ 物块阻尼              │ U(0.5*, 2.0*)            │
  │ 工作台高度            │ U(0.85*, 1.15*)          │
  │ 位置控制器增益         │ U(0.9*, 1.1*)           │
  │ 动作时间步长           │ U(0.5*, 1.5*)            │
  │ 观测噪声              │ N(0, 0.05) 加到52维      │
  └──────────────────────┴──────────────────────────┘
  * = 标称值的倍数

  关键洞察: 物块质量的随机化范围 (0.25-4.0*) 远大于连杆质量
  (0.5-1.5*)。因为物块是交互对象，其真实质量变化范围确实更广
  （可以推不同重量的物体），而机器人自身连杆质量相对固定。
  —— "根据先验知识调整每个参数的随机化宽度"

[原则 3: 范围从宽开始，逐步收窄]

  1. 第一轮: 用非常宽的范围（如 0.25-4.0*）训练
  2. 观察: 如果策略在真实世界表现良好，收窄范围提高性能
  3. 迭代: 直到找到"刚好能迁移"的最窄范围

  好处: 从宽到窄容易（有性能数据指导），从窄到宽困难
  （不知道要多宽才够）。

[为什么动力学随机化有效 — 数学直觉]

  训练分布（宽范围随机化）:  >>>>>>>>>>>>>>>>>>>>>>>>
  真实系统参数:                          ||
                                        v
                           训练覆盖了真实参数
                           策略学会了应对这个范围

  训练分布（窄范围/无随机化）:          >>>
  真实系统参数:                         ||
                                        v
                           真实参数在训练分布之外
                           策略遇到未见过的动力学
                           → 失败

[对你的 A2 实验的启发]

  Peng 方法论                         映射到你的项目
  ─────────────────────────────────────────────────────────────
  每 episode 固定随机化                Rand 模式: sigma~U(0,2.0),
                                      每 episode 开始时采样一次
  隐式系统辨识 (LSTM)                 你的策略是 MLP (无记忆),
                                      这是方法论的差异点
  范围要宽                            sigma=2.0 full 噪声已导致
                                      42% 成功率 (A1数据),
                                      这可能是你的上界
  从宽开始收窄                        Curric 模式的 sigma
                                      0->2.0 线性增长, 正是
                                      "逐步加宽"的实践

  └──────────────┴─────────────────────┴─────────────────────┘

[你的 A2 实验对应关系]

  你的 A2-Fixed:   sigma=0.5 固定全维噪声
                   → 对应 Ferede 的某个 % 水平
                   → 对应 Peng 的窄范围训练

  你的 A2-Rand:    sigma ~ U(0, 2.0) per episode
                   → 对应 Peng 的核心方法论
                   → 对应 Ferede 的宽范围

  你的 A2-Curric:  sigma: 0 -> 2.0 线性增长
                   → 对应 Peng 的"从窄到宽"原则
                   → 你的创新点（两篇论文都没有做curriculum）

[关键待回答问题]

  1. sigma=2.0 的 Full 噪声是否已经是上界？
     （A1 数据: 42% 成功率 @ sigma=2.0 full）
  2. Rand vs Curric 哪个更好？
     → A2 跑完对比
  3. 无记忆 MLP 在随机化训练中是否比有记忆 LSTM 差？
     → 未来可探索的方向（如果 Rand 效果不好, 可尝试加 LSTM）
  4. 噪声是否应该 per-episode 固定而不是每步随机？
     → 你当前的 noisy env 是每步随机加噪声 (对应传感器噪声)
     → Peng 的建议: 动力学参数应该 per-episode 固定
     → 两种噪声类型可能需要不同的注入策略

四、对后续实验的具体建议
============================================================

[建议 1: Rand 模式的噪声应该 per-episode 固定]

当前 noisy env: 每个 timestep 调用 _get_observation() 时生成
新的随机噪声。对应"传感器噪声"（高频、每步变化）。

Peng 式随机化: 每个 episode 开始时采样一个 sigma, 整个 episode
使用同一个值。对应"动力学参数不确定性"（低频、episode 内不变）。

建议: A2-Rand 中使用 per-episode 固定的 sigma 值。
这需要修改环境或训练循环，在 reset() 时采样 sigma 并缓存。

[建议 2: 上界选择]

A1 结果显示 sigma_full=2.0 时成功率仅 42%, sigma=1.0 时 78%。
A2-Rand 的 U(0, 2.0) 范围合理——覆盖了从易到难的完整范围。
如果 Rand 效果差（平均 sigma=1.0 导致成功率偏低），
可考虑缩小到 U(0, 1.0)。

[建议 3: Curric 的增长速率]

500 轮, sigma 从 0 到 2.0:
  每轮增长 = 2.0 / 500 = 0.004
  前 100 轮在 sigma < 0.4 (安全区)
  后 100 轮在 sigma > 1.6 (危险区, 成功率急剧下降)

这个增长速率合理——策略在"安全区"建立基本能力,
在"危险区"逐步适应极端噪声。
