## 5. AI 协作约定（继承自《认知债务防御手册 V2》）

每次生成本项目代码时：
1. 先读 CLAUDE.md（本文件）+ docs/knowledge-map.md
2. 一个 Prompt = 一个模块（≤200 行），不要一次生成整个功能
3. 交付时附带知识包：位置 + WHY + 数据流 + 边界 + 风险点
4. 生成 3 个"理解自测"问题
5. 检查 docs/knowledge-map.md 是否需要更新
6. 永远不要只交付代码——交付：代码 + 理解 + 质量保证

## 6. 红线（绝对禁止）

- 禁止硬编码密钥、Token、密码
- 禁止使用 eval() 或等效动态执行

- 禁止修改已存在的核心文件，除非先获确认
