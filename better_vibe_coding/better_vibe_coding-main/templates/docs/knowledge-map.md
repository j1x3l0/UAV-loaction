# 知识地图 — Knowledge Map 模板（认知债务防御 V2 第 2 防御层）

> 作用：回答"系统长什么样？"。是团队的认知地图，由 `@knowledge-map-maintainer` 维护。
> 任何代码改动后都应检查本文件是否需要更新。
> 删除所有 `<占位符>` 与示例行后投入使用。
> 更新原则：宁可新增一行，也不要让一段过期——过期比缺失更危险。

---

## 3. 雾图（Fog Map）—— 模糊区与单点故障

| 区域 | 现状 | 风险等级 | 待澄清项 |
|------|------|----------|----------|
| <示例:支付回调> | 异常路径未覆盖 | 高 | 重复回调如何幂等？ |
| <示例:Redis 缓存> | 失效策略不清晰 | 中 | 是否有 dogpile 风险？ |

> 雾图越厚，认知债务越高。每次合并都应收窄雾图，至少不让它变厚。
